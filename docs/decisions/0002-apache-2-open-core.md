# 0002: Apache 2.0 for core and basic typing (open core)

Status: Accepted, amended by [0004](0004-license-mit-or-apache-for-new-code.md) (new code is MIT OR Apache-2.0)
Date: 2026-11-17

## Context

The original Buuz was released under Apache 2.0. We want the typing engine to
be trusted, reusable and open to contribution.

## Decision

The core and basic typing in this repository are licensed under Apache 2.0,
with the original author credited in `NOTICE`. Optional extras may be developed
outside this repository under separate terms; the open typing experience is not
reduced to make room for them.

## Consequences

- Anyone may use, fork and embed the typing core, including commercially.
- Contributions are licensed under Apache 2.0 (see CONTRIBUTING.md).
