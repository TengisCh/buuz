# Decision log

Short records of technical decisions (ADR style), so contributors can see what
was chosen and why. One file per decision, numbered in order.

Scope: technical decisions only (architecture, typing rules, licensing of the
code). Business decisions are not tracked here.

To propose a change, open an issue or Discussion first. If accepted, add a new
record that supersedes the old one instead of editing history.

## Template

```
# NNNN: Title
Status: Proposed | Accepted | Superseded by NNNN
Date: YYYY-MM-DD

## Context
## Decision
## Consequences
```
